# 博客智能助手

## 回答流程

请求携带问题、标签页会话标识、最近对话和当前文章定位。模型先规划初始路径，再依据工具证据决定继续查找、阅读或给出答案；初始路由不是固定执行链。

每轮最多执行 5 次只读工具调用；重复的工具与参数不会重复执行。阶段间检查 120 秒预算，单次上游请求仍受 HTTP 超时约束。工具参数统一校验类型、长度和未知字段，工具异常不直接公开内部信息。

## 八个公开工具

| 工具 | 用途 |
| --- | --- |
| blog_qa | 全站或当前文章的向量与关键词混合检索 |
| blog_summary | 完整有序分块摘要，按正文指纹和摘要重点缓存 |
| weather | 查询真实天气数据 |
| search_posts | 目录统计、标题关键词、分类、标签、发布日期和分页 |
| read_post_outline | 获取文章章节目录与稳定的本次章节编号 |
| read_section | 按章节编号或标题分段阅读原文 |
| read_post | 分页阅读指定文章正文 |
| get_site_profile | 获取确认过的站点和作者公开信息 |

普通聊天、笑话、翻译和一般技术问题直接使用模型能力，不建立固定答案工具。公共网页搜索、识图、服务器执行能力未开放。

目录统计直接读取公开 Markdown，不使用相似度检索结果推断文章数量。目录关键词筛选不是语义搜索，主题语义召回应使用 blog_qa。草稿不进入目录或索引。

## 证据与上下文

工具每次返回的局部引用编号会映射为本次回答的全局编号。最后按实际引用次序整理角标；没有引用标记时不强行添加第一条引用。文章、用户提供的页面信息及工具文本均视为资料，不得作为系统指令。

浏览器聊天只保存在当前标签页内存，同站导航保留，刷新关闭后清空，不写入 localStorage。服务端会话为进程内存，默认闲置 30 分钟过期，最多 500 个会话、8 条消息、每条 1000 字符；另外保留最近文章列表、已解析文章和最近证据定位，帮助还原“第二篇”“刚才那篇”等指代。重启会清空，不跨设备同步。

原文读取返回 nextOffset，未读部分不能声称已经阅读。超长对话不做无限保存或隐式长期记忆，必要时应重新查证。

## 索引更新与回滚

增量更新先完成向量生成，再整篇写入，成功后清理缩短文章的尾部分块，避免先删旧内容。维度变化禁止自动删除原集合。

全量重建要求 QDRANT_COLLECTION 指向别名，例如 blog_chunks_live。先写入独立的 blog_chunks_live_build_* 集合，校验分块数量后原子切换别名；失败保持旧索引可用。旧集合保留，确认线上效果后再人工清理；失败留下的构建集合也需定期检查，避免存储累积。

初次迁移只需给现有 blog_chunks 建立 blog_chunks_live 别名，不必重算向量。回滚时将该别名原子指向上一物理集合，不要删除线上别名或正在使用的集合。

## 验证

本地执行 `mvn test`，覆盖工具参数安全、跨工具证据编号、多步调查、目录分页筛选、分段阅读、摘要缓存失效、结构化上下文、Qdrant 分页和重建失败保护。公网使用基础设施仓库的 `host/verify-blog-models.py`，结合实际文章执行目录查询、跨文章比较和上下文追问验收。
